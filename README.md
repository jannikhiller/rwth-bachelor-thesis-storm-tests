# Bachelor’s thesis Storm tests

Models and scripts for the experiments in [Model Checking Stochastic Games with Storm](https://github.com/jannikhiller/rwth-bachelor-thesis).

- [`compare.py`](compare.py) compares Storm and PRISM-games results.
- [`measure_runtimes.py`](measure_runtimes.py) records model checking runtimes.
- [`examples/`](examples/) contains example PRISM models and property files. The random example uses [`random.prop`](random.prop).
- [`smgs/`](smgs/) contains the stochastic multiplayer game benchmarks.
- [`results/random/`](results/random/) contains saved random model outputs.
